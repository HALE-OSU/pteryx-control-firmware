# Pteryx Software

A mono-repo for everything Pteryx

`/stack-firmware` - The main firmware running on a Pteryx stack

`/dashboard` - A web-based dashboard for configuring and testing Pteryx hardware

`/stm-drivers` - Firmware for running STM32 microcontrollers that are used on some Pteryx modules
